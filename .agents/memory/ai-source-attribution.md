---
name: AI source attribution
description: Правило выбора источников для ответов AI-чата
---

Источники AI-ответа должны подтверждаться ID материалов из переданного модели контекста; нельзя автоматически добавлять лучший результат поиска, если модель его не использовала.

**Why:** Ранжирование поиска может выбрать похожий общий материал вместо конкретной инструкции, из-за чего пользователь видит ссылку на неверный документ.

**How to apply:** Просить модель возвращать проверяемые SOURCE-маркеры, фильтровать их по текущему контексту и показывать только валидированные материалы; при отсутствии маркеров использовать только материалы с существенным совпадением ответа.
